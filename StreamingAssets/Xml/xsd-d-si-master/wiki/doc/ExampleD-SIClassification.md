# Examples: XML data with different D-SI classification

The D-SI considers different classes of machine-readbility of data according to the units of measure that are used and the completenes of the metrological information. In the figure below, these classes are outlined by medals.

<img alt="D-SI-Medals" width="600" style="border-width:10" src="wiki/doc/Medals.PNG" /></a>

For each of the medals, the D-SI XML format comes with collections of comprehensive XML examples.
